# Évasion Azur — Maison de Haute Confection de Voyages d'Exception

Une landing page haut de gamme, moderne et minimaliste conçue sur un fond blanc immaculé avec une palette dominée par le bleu azur et le turquoise.

## Caractéristiques d'Exception

- **Design Minimaliste & Haut de Gamme** : Fond blanc immaculé, touches d'azur profond et de turquoise lagon, typographie contemporaine (*Syne*, *Plus Jakarta Sans*, *Cormorant Garamond*).
- **Animations de Décollage Aérien Fluides** :
  - **Au survol des destinations** : Silhouette de jet vectoriel qui prend son envol sur une trajectoire courbe ascendante avec traînée de condensation lumineuse.
  - **Au clic sur les boutons d'appel à l'action (CTA)** : Animation dynamique d'un avion supersonique VIP qui décolle depuis le bouton et traverse l'écran vers le ciel, laissant un sillage de particules azur et turquoise, suivi de l'apparition d'un Boarding Pass VIP interactif.
  - **Synthétiseur sonore Web Audio (Optionnel)** : Chime cristallin et souffle aérodynamique doux de réacteur activable via le bouton de volume.
- **Arrière-plan Céleste Vivant** : Canvas haute performance avec traînées de condensation d'avions de ligne à haute altitude et particules scintillantes.
- **Section Héros avec Planificateur de Vol** : Recherche sur-mesure (destination, saison, jet privé/première classe).
- **Catalogue de Sanctuaires Confidentiels** : Bora Bora, Capri, Maldives, Santorin, Kyoto, Norvège, avec filtrage par catégorie.
- **L'Atelier Sur-Mesure** : Formulaire interactif de création d'itinéraire exclusif.
- **Livre d'Or & Conciergerie 24/7** : Témoignages et engagements d'excellence.

## Comment visualiser la page

### Option 1 : Ouvrir directement dans le navigateur
Ouvrez simplement le fichier `index.html` dans votre navigateur web préféré :
```bash
xdg-open index.html
```

### Option 2 : Serveur local rapide
```bash
python3 -m http.server 3000
```
Puis accédez à `http://localhost:3000` dans votre navigateur.
